# coc-lab v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prototipe otomasi CLI (observe/live) yang menjalankan satu siklus penuh: connect ADB → cari tombol attack → matchmaking → cek loot (OCR) → serang sederhana → kembali home.

**Architecture:** Paket Python kecil `coclab/` dengan modul terpisah per tanggung jawab (config, adb, capture, vision, actions, state, loop). Semua aksi fisik lewat satu gerbang (`Actions`) yang sadar mode observe/live. `loop.run()` menerima injection `Deps` agar bisa diuji penuh dengan fake tanpa ADB/game.

**Tech Stack:** Python 3.14 (`py` launcher), numpy, opencv-python 4.13 (terpasang), rapidocr-onnxruntime (opsional, lazy import), subprocess → adb.exe. Tanpa dependensi lain.

**Spec:** `docs/superpowers/specs/2026-10-15-coc-lab-v1-design.md`

## Global Constraints

- Kode 100% original; dilarang menyalin kode dari hasil decompile CROWZ. Semua perilaku di plan ini bersumber dari spec (hasil analisis).
- Python dijalankan via `py` (alias `python` rusak di mesin ini). Test: `py -m pytest`.
- Windows paths; semua eksekusi subprocess memakai list-argumen (bukan string shell).
- Mode default `observe` (nol aksi fisik); `--live` wajib eksplisit. `--cycles` default 1.
- Default threshold `0.69`; fallback resolusi `1600×900`; delay tap `150ms`.
- Jangan commit artefak game: `assets/*.png`, `work/`, `logs/`, `config.json` di-ignore.
- Identitas kode/log berbahasa Inggris; README ringkas boleh Indonesia.

## Review Focus

1. `adb_path` salah/ber-spasi (mis. "coc bot") → error jelas `AdbError`, bukan traceback `FileNotFoundError`.
2. Screenshot setengah tertulis (pull terputus) → `is_valid_image` menolak → `capture` retry, bukan crash cv2.
3. `config.json` tidak ada / field salah → pesan menunjuk `config.example.json`, exit code jelas.
4. OCR salah baca (digit nyambung/ekstrem) → angka >9 digit dianggap gagal (`None`) agar tidak menyerang dengan data palsu.
5. Ctrl+C di tengah run → keluar bersih (exit 130) tanpa traceback, tanpa aksi tambahan.

# tests/test_vision.py
import cv2, numpy as np
from coclab.vision import find_template, is_valid_image, load_image

def _canvas_with_block(cx, cy, size=24):
    img = np.zeros((200, 300, 3), np.uint8)
    tpl = np.full((size, size, 3), (0, 0, 255), np.uint8)
    img[cy:cy+size, cx:cx+size] = tpl
    return img, tpl

def test_find_template_exact_position():
    img, tpl = _canvas_with_block(120, 60)
    m = find_template(img, tpl, 0.9)
    assert m.found and m.score > 0.99
    assert abs(m.cx - (120 + 12)) <= 1 and abs(m.cy - (60 + 12)) <= 1  # center

def test_find_template_negative():
    img, tpl = _canvas_with_block(120, 60)
    other = np.full((24, 24, 3), (0, 255, 0), np.uint8)
    m = find_template(img, other, 0.9)
    assert not m.found and m.score < 0.9

def test_find_template_rejects_oversized_template():
    img = np.zeros((50, 50, 3), np.uint8)
    tpl = np.zeros((80, 80, 3), np.uint8)
    m = find_template(img, tpl, 0.9)
    assert not m.found and m.score == 0.0  # Review Focus #2 adjacent: no crash

def test_is_valid_image_rejects_truncated(tmp_path):
    img, _ = _canvas_with_block(10, 10)
    ok = tmp_path / "ok.png"; cv2.imwrite(str(ok), img)
    bad = tmp_path / "bad.png"; bad.write_bytes(ok.read_bytes()[:  len(ok.read_bytes()) // 3])
    assert is_valid_image(ok) is True
    assert is_valid_image(bad) is False          # Review Focus #2
    assert is_valid_image(tmp_path / "missing.png") is False

def test_load_image_returns_bgr_array(tmp_path):
    img, _ = _canvas_with_block(10, 10)
    p = tmp_path / "x.png"; cv2.imwrite(str(p), img)
    arr = load_image(p)
    assert arr.shape == (200, 300, 3)

import pytest
from pathlib import Path
from coclab.adb import Adb, AdbError

class FakeRunner:
    def __init__(self, responses): self.responses, self.calls = list(responses), []
    def __call__(self, args):
        self.calls.append(args); return self.responses.pop(0)

def test_connect_returns_matching_serial():
    r = FakeRunner([(0, b"connected to 127.0.0.1:5555\n", ""),
                    (0, b"List of devices attached\n127.0.0.1:5555\tdevice\n", "")])
    a = Adb("adb.exe", r)
    assert a.connect("127.0.0.1:5555") == "127.0.0.1:5555"
    assert r.calls[0] == ["adb.exe", "connect", "127.0.0.1:5555"]

def test_wm_size_prefers_override_then_physical_then_fallback():
    out = b"Physical size: 1080x1920\nOverride size: 720x1280\n"
    r = FakeRunner([(0, b"List of devices attached\n127.0.0.1:5555\tdevice\n", ""), (0, out, "")])

# tests/fakes.py
import numpy as np
from pathlib import Path
from coclab.loop import Deps
from coclab.vision import Match

class RecordingAdb:
    def __init__(self): self.taps = []
    def tap(self, d, x, y): self.taps.append((x, y))

class FakeActions:
    def __init__(self, adb, device, mode, screen):
        self.adb, self.device = adb, device
    def tap_percent(self, xp, yp): self.adb.tap(self.device, int(xp * 1600), int(yp * 900))
    def tap_px(self, x, y): self.adb.tap(self.device, x, y)

def make_deps(script, states):
    """script: {nama_template: Match}. fake find_template membaca Path(tpl).name."""
    def find_template(img, tpl, threshold):
        return script.get(Path(tpl).name, Match(False, 0, 0, 0.0))
    deps = Deps(
        adb=RecordingAdb(),
        capture_fn=lambda adb_, dev, dest, retries=2: True,
        load_image=lambda p: np.zeros((10, 10, 3), np.uint8),
        find_template=find_template,
        crop_percent=lambda img, *a: img,
        ocr_digits=lambda img, engine=None: 999999,
        actions_factory=lambda a, d, m, s: FakeActions(a, d, m, s),
        sleep=lambda s: None,
        monotonic=lambda: 0.0,
        state_hook=lambda st: states.append(st),
    )
    return deps, deps.adb

def full_script(**overrides):
    base = {"attack.png": Match(True, 1, 1, .95), "find_match.png": Match(True, 1, 1, .95),
            "searching_for_opponents.png": Match(False, 0, 0, .1),
            "returnhome.png": Match(True, 1, 1, .95)}
    base.update(overrides); return base
