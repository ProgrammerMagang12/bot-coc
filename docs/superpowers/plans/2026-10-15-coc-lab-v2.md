# coc-lab v2.1 Implementation Plan (multi-drop troops + wall upgrade)

> **For agentic workers:** jalankan task berurutan; TDD per task (test RED → implement → PASS → commit). Titik henti: sebelum serangan live & sebelum kalibrasi wall (manual bersama operator).

**Goal:** `attack()` melakukan serangan multi-drop (dragon→balloon→siege) dari file strategi; modul wall upgrade siap + default nonaktif.

**Spec:** `docs/superpowers/specs/2026-10-15-coc-lab-v2-design.md`

**Global Constraints:** kode orisinal; semua parameter via config; tidak menyentuh asset/kode CROWZ; Windows + `py`; suite harus hijau tiap task.

---

### Task 1: strategy.py + config v2

**Files:** Create `coclab/strategy.py`; Modify `coclab/config.py`, `config.example.json` (dan `config.json` lokal); Test `tests/test_strategy.py`, `tests/test_config.py` (tambahan).

**Interfaces:**
- Produce: `strategy.StrategyError`, `strategy.Strategy`, `strategy.load_strategies(path) -> list[Strategy]`
- Config baru: `strategy_file: str`; `card_points: dict[str, list[float]]` (keys wajib: dragon, balloon, wall_wrecker); `wall_upgrade: dict` (lihat spec; validasi: enabled bool, gold_min int>0, 4-roi ordered, points 2-persen, max_scroll_tries int>0)

**Steps:**
1. Tests (RED): load valid file (tmp_path JSON) → 2 strategi; name kosong → error; titik 1.5 → error; grup kosong semua → error; config example memuat `card_points` & `wall_upgrade` (assert tipe & default enabled False); `wall_upgrade.gold_min` negatif → error.
2. Run pytest → FAIL.
3. Implement `strategy.py` + tambahkan field/validasi config + contoh JSON.
4. Run pytest → PASS (suite lama tetap hijau).
5. Commit: `feat: strategy loader and v2 config fields`

### Task 2: attack() multi-drop + fallback

**Files:** Modify `coclab/loop.py`; Test `tests/test_loop.py` (tambahan).

**Steps:**
1. Tests (RED): dengan strategi fake (dragon 2 titik, balloon 1 titik, ws 1 titik) & `Actions` asli → urutan tap = [card_dragon, d1, d2, card_balloon, b1, card_ws, ws]; tanpa strategi (file kosong/missing → fallback) → urutan v1 tetap (card lama + drop_points).
2. Run → FAIL.
3. Implement: `deps` tambah `load_strategies` (default `strategy.load_strategies`); `attack()` sesuai spec A; log "Executing Scenario".
4. Run → PASS.
5. Commit: `feat: multi-drop attack sequence with strategy fallback`

### Task 3: tools/make_strategy.py

**Files:** Create `tools/make_strategy.py`; Test `tests/test_make_strategy.py`.

**Steps:**
1. Tests (RED): `points_to_percent([(100,50)], (200,100)) == [(0.5,0.5)]`; `save_strategy(name, dragon, balloon, wrecker, path)` menulis JSON yang valid & bisa dibaca `load_strategies`.
2. Run → FAIL.
3. Implement tool (GUI single-window: klik menambah titik; d/b/w pindah grup; u undo; s save; q quit) + fungsi non-GUI.
4. Run → PASS (GUI manual nanti).
5. Commit: `feat: strategy calibration tool`

### Task 4: vision.ocr_text + wallupgrade.py

**Files:** Modify `coclab/vision.py`; Create `coclab/wallupgrade.py`; Test `tests/test_wallupgrade.py`.

**Steps:**
1. Tests (RED): `ocr_text` pakai engine injectable (`lambda _: "Upgrade Wall"`) → mengembalikan string; wallupgrade dengan deps fake: gold rendah → `skipped(low gold)`; gold cukup + "wall" ketemu di iterasi ke-2 → urutan tap: [logo click, wall text click, gold upgrade, gold confirm, elixir upgrade, elixir confirm]; max scroll habis → status gagal dengan alasan.
2. Run → FAIL.
3. Implement `ocr_text` (pakai `_load_default_engine` yang sama) + `wallupgrade.run_wall_upgrade(cfg, deps, actions, shot_fn) -> WallResult` dengan struktur sesuai spec B (template `upgrade_logo` dicari via deps.find_template; swipe via actions? tambah `actions.swipe_percent`? — gunakan `self.actions` baru: tambahkan `swipe_percent` ke `Actions` + test).
4. Run → PASS.
5. Commit: `feat: wall upgrade module with OCR wall search`

### Task 5: wiring + docs

**Files:** Modify `coclab/loop.py` (panggil wallupgrade setelah return_home bila enabled), `README.md`, `config.example.json`; Test `tests/test_loop.py` (test wiring: enabled + fakes → wallupgrade dipanggil; disabled → tidak).

**Steps:**
1. Tests (RED) → 2. FAIL → 3. Implement wiring (import ringan; kegagalan wall tidak menggagalkan siklus — log & lanjut) → 4. PASS → 5. Commit: `feat: optional wall upgrade wiring + docs`

### Task 6 (manual, bersama operator): kalibrasi live

1. **card_points**: screenshot bar pasukan di battle → aku anotasi nomor → operator konfirmasi kartu dragon/balloon/wrecker → set config.
2. **strategi pertama**: dari screenshot scout → operator pilih 3-4 titik dragon + 2 titik balloon (+ws) → `make_strategy` → simpan.
3. **Serangan live**: `py main.py --live --cycles 1` + sniper → bukti "Troops expanded" & loot.
4. **Wall (opsional lanjut)**: capture `logo_up.png` + titik-titik → enabled true → uji.
